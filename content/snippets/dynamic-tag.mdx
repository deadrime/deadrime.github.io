description: React component with dynamic tag (as prop)

Компонент с динамическим тегом — проп `as` определяет какой элемент будет отрендерен.

## Утилитный тип

```tsx
import { type ComponentPropsWithRef, type ElementType } from 'react';

type PolymorphicProps<
  C extends ElementType,
  OwnProps = Record<string, never>,
> = OwnProps &
  Omit<ComponentPropsWithRef<C>, keyof OwnProps | 'as'> & {
    as?: C;
  };
```

## React 19+

В React 19 `ref` можно передавать как обычный проп — `forwardRef` не нужен:

```tsx
type BoxOwnProps = {
  padding?: 'sm' | 'md' | 'lg';
};

export const Box = <C extends ElementType = 'div'>({
  as,
  padding = 'md',
  className,
  children,
  ref,
  ...props
}: PolymorphicProps<C, BoxOwnProps>) => {
  const Component = as || 'div';

  return (
    <Component ref={ref} {...props} className={`p-${padding} ${className || ''}`}>
      {children}
    </Component>
  );
};

```
Использование:

```tsx
<Box>Default div</Box>
<Box as="a" href="/link">Link</Box>
<Box as="section" ref={sectionRef}>...</Box>
```

## React 18 и ниже

Понадобиться хелпер `fixedForwardRef` + generic функция:

```tsx
import { forwardRef, type ElementType } from 'react';

// Хелпер для сохранения дженериков в forwardRef
function fixedForwardRef<T, P>(
  render: (props: P, ref: React.Ref<T>) => React.ReactNode,
) {
  return forwardRef(render as any) as (
    props: P & React.RefAttributes<T>,
  ) => React.ReactNode;
}
```
Пример:
```tsx
type BoxOwnProps = {
  padding?: 'sm' | 'md' | 'lg';
};

const BoxRaw = <C extends ElementType = 'div'>(
  props: PolymorphicProps<C, BoxOwnProps>,
  ref: React.Ref<Element>,
) => {
  const { as, padding = 'md', className, children, ...rest } = props;
  const Component = as || 'div';

  return (
    <Component ref={ref} {...rest} className={`p-${padding} ${className || ''}`}>
      {children}
    </Component>
  );
};

export const Box = fixedForwardRef(BoxRaw);
```
